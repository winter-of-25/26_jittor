# 实验历程

本文档记录从最初复现到最终 B24 的主要演进，便于评委和后续开发者理解为什么最终模型采用现在的结构。

## 1. 复现与调参阶段

最初从 StraightPCF / IterativePFN 风格 baseline 出发，复现分数约 73.61。随后尝试学习率、训练轮数、推理 patch 参数、checkpoint 选择、轻量 head 等常规方向，逐步提升到 74-77 分段。

这一阶段的结论是：单纯复现和调参可以带来提升，但很快遇到上限，必须改变模型结构和训练目标。

## 2. V12 稳定基座

V12 达到约 80.70，成为第一个稳定可复用的强基座。它证明 patch-based 去噪路线适合赛道数据，P2S 可以通过更稳的局部表面约束获得较高分，后续应以 V12 作为 parent，而不是频繁从零开始。

## 3. V29-V45：结构探索阶段

V29 首次突破到 81.37，说明架构方向有效。随后 V33/V34、V40/V41、V45/V46 形成多轮竞争：

- V33/V34：局部 residual 与正则化策略更有效；
- V40/V41：进一步稳定 CD；
- V45：成为 A榜后期最重要的基座之一。

这一阶段的经验是：有效提升往往来自“主干能力 + 有约束修正”，而不是完全抛弃已有基座。

## 4. V65：A榜最终强方向

V65 达到 A榜 83.13，是 A榜后期保留的最强方向。它强化了局部细节修正与 patch 融合，但在 B榜数据上直接迁移并不一定最优。

## 5. B榜迁移阶段

B榜开放后，先尝试 A/B 数据融合、B-only 微调和多种新结构。早期 B01-B05 在 80.69-80.74 附近，说明直接迁移 V65 只能得到一个可用但不够强的起点。

随后尝试 B14-B19 多条结构路线，成绩集中在 80.98-81.04，说明“小结构变体”有提升但不足以产生决定性突破。

## 6. B20-B24：稳定高分阶段

B20 达到 81.41，说明 B榜适配方向成立。B24 在 B20 的基础上做 CAVR-v2：固定 teacher，避免已有能力丢失；student 只学 bounded residual；CAGrad 同时处理 CD/P2S；用固定验证选择 checkpoint 与 residual strength；测试推理前严格检查 hash 与 selection lock。

最终 B24 得到 B榜 81.44，成为最终提交版本。

## 7. 为什么停止在 B24

后续又尝试了 router、多专家、patch gate、point gate 等方向。这些方法理论上有局部互补性，但受限于可提交次数、本地 proxy 与线上评测偏差、router 误判风险和复杂方法的稳定性，最终选择 B24 作为性能、稳定性和复现性之间最平衡的版本。
